# Decision after the original HL-V1 adequacy gate

The original KITTI05/06 pilot is INCONCLUSIVE for inadequate real cohorts.
No H1/H2 scientific conclusion or training authorization follows. Preserve
pilot-01 and its discovery freeze; do not regenerate it with changed rules.

Decision: further direction validation should first expand the **data audit**,
not fit a selector or sweep cutoffs on these outcomes. Use the previously
proposed MulRan repeated-route data as the first inventory target; exact
sessions, download availability, GT/extrinsics/timestamps, route/site separation,
prior local use and source ranges must be verified before naming a new cohort.
This document does not invent sessions or claim their adequacy. RAP pretraining
membership remains unresolved; new-to-project is not independent of pretraining.

The next continuation should perform a bounded metadata/access inventory and
write an explicit data-expansion annex before new registration outcomes. The
annex should predeclare session order, discovery/confirmation roles, candidate
geometry, the same strict metric denominators and adequacy stopping rules. A
data-only cohort check should precede RAP inference again. Do not select sessions
by model success or use unsupported sequences to claim an H1/H2 failure.

Keep the original support rule for comparable data audits. If the same-keyframe
2m/5m collapse persists, a possible separate amendment is selecting causal raw
scan supports instead of keyframes while preserving anchor exclusion and the
age/distance criteria. This is **a proposed protocol change, not adopted here**;
its geometric/RNG/resource validation and changed observation budget would need
to be frozen and reported before a scored run. It cannot alone solve the
observed absence of hard strata in KITTI05/06, so do not use it as a shortcut.

No large download, new experiment, changed thresholds, split or training is
initiated by this record. The next concrete output is a verified data inventory
and a prospective annex; HL2 remains conditional on a later adequate pilot.
