## 状态怎么读

`execution_state` 只在已核对的关键档案中填写；其余保留 null，并提供原 STATUS 声明或原文摘录。null 不是成功或失败。`record_state` 说明资料登记情况，不表示实验已完成。

目的、状态和失败/预算摘录带原文件 ID、行号和截断标记。摘录可能涉及一次失败尝试或负对照，不自动成为整项研究结论。代码/输入/seal 列表只表示证据文件存在，不代表所有声明均已通过校验；原差异继续见 A1 缺口表。

同一文档出现在外部 Codex 档案和仓库副本时，索引保留原位置并标识相同字节关系；不计作独立试验或独立采集。482 条目首版基于 A1 的不可变清点，另接入 A1/A2 维护档案；覆盖范围和生成收据保存在本轮 A2 记录中。

## 更新方式

新阶段先更新当前状态和根 AGENTS，再添加有来源的档案条目；不改旧原文。重新生成索引需明确采用哪份资产清点或新增记录，保存前版/变更及覆盖检查；不得让索引扫描自己的镜像、备份或源码缓存而形成递归重复。
