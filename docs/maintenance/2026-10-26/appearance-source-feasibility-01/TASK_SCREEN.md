# Appearance task screening before any new numerical experiment

Measured image content is the proposed additional channel. Existing LiDAR intensity, radial visibility, persistence masks and scalar consistency failures remain closed. A new measured sensor channel would be a substantive observation change, but neither a generic image score nor sensor fusion by itself is an originality claim.

Historical F2 and rejection diagnostics narrow the useful question. Most08 failures lack any strictly correct K4 candidate, and the strictly incorrect accepted poses are not evidence of gross false-place matches. Thus whole-image place recognition or merely reranking the same four wrong poses cannot solve that demonstrated pose-error mechanism. We should not obtain images under a misleading claim that they will fix it.

A potentially useful different question is whether calibrated image observations contain an executable pose-conditioned correction or additional metric correspondence that ordinary same-input geometry misses. An ordinary visual geometric solver must be a strong control; if it solves the problem independently, the result is an engineering contribution rather than a RAP-specific gain. No such method, pose or score is implemented here.

Necessary prerequisites before a later pilot:

1. Bind actual image files, official frame IDs/camera identity, image dimensions, projection/extrinsic action and timestamps to the existing complete input population. Existing supplied-reference KITTI remains exposed engineering data; no unseen-site or independent physical claim.
2. Establish camera co-observation adequacy. A front-facing camera does not cover every360-degree LiDAR loop. A positive-depth or hypothetical-frustum calculation is only an upper-bound/proxy check, not proof of actual visible image correspondences.
3. State how the LiDAR intrinsic-correction and camera projection conventions interact. Do not invent an inverse correction, per-point timing or calibration change to improve a score.
4. Before reading new outcomes, fix the complete observed-development population, geometry/visual/RAP controls, failure/no-support handling, primary useful effect and adverse tails. Do not select only pairs with favorable ground-truth visibility or tune on an alleged reserved cohort.
5. Count actual input acquisition/preparation, any feature computation, all solvers/failures/transfers and evaluation. Source access and a successful metadata worker do not admit fitting or a full-system expansion.

First action is the bounded source-page decision and complete camera-member requirement, not another synthetic prototype. The existing200-pair input manifest is used only to enumerate prospective source member IDs; all numeric tokens in that read are lexical strings, and no pose/reference values are used. No image or raw point content has been read, and no efficacy protocol is frozen.
