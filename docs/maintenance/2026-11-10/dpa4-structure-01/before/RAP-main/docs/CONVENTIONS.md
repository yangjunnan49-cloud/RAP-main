# 当前项目约定

本文件统一当前工程维护口径；旧协议、原始结果和封存文件保留原文。当前任务、阶段和研究状态分别以根 AGENTS、CURRENT_STATE.json/生成页和实验原报告承担不同职责。

## 工作区与仓库

- RAP-main 保存模型、预处理、推理配置与研究维护工具；RAP-SLAM 保存下游系统。两个仓库独立管理，当前阶段保留边界。
- 报告、Datasets、外部 Codex 档案、组会和旧维护副本均纳入迁移资产。全部实验历史最终常驻服务器，原件不能由重跑替代。
- 工作区父级 AGENTS 只规定共通边界；仓库 AGENTS 规定本仓库入口与操作要求；本页规定共用术语。详细指标只在状态页引用与原协议/报告中解释，避免反复复制历史全文。

## 语言、时间和命名

- 当前 AGENTS、维护说明和迁移指南以中文为主；代码标识、代码注释和原有接口沿用英文；历史文档不翻译改写。
- 人类阶段日期使用 YYYY-MM-DD 和 Asia/Shanghai；机器观察使用带时区的 UTC。事件发生、观察、后补文档分别记录，不能回填成原实验执行时间。
- 原实验 ID、输出目录和文件名保持原值。索引 ID 使用 `root_id:relative/path` 表示档案位置，不把它当作独立科学实验编号；同份文档的多个副本显式关联。
- 缺失或未验证字段写 null/未知/待核对；不能从现默认值或“目录存在”推断历史参数、数据完整性或成功。

## 变换与输入语义

- `RAPBackend.register(a,b)` 现有方向为 b→a，即 b 在 a 中的位姿；保持其与 BetweenFactor 使用的一致语义。
- 保留当前归一化、点数/特征条件、随机数、精度策略与输入/输出合约。`x_0`、`x_1`、`x_t`、`v_t` 沿用代码原定义；可选初始化通道存在不等于实际测试或训练准入。
- KITTI 相机位姿、LiDAR/world、POSS 和原始/0.205° 校正点云分别按对应协议解释。不能为迁移整洁混用坐标、自动补校准或统一改写冻结参数。
- 保留 SDPA attention 路径、可选依赖延迟导入和现有精度作用域；父级旧文档中的全局精度描述不能替代当前 rap_precision.py 与已冻结源码。

## 路径和环境

- 当前文档导航采用相对链接；历史外部来源在索引中用根 ID 与原相对路径登记。[路径解析说明](experiments/PATHS.md)区分本机来源、档案副本与未来服务器路径。
- 五项当前离线任务通过[统一启动器](code/RUNNING.md)配置根、数据、权重、输出与缓存；优先级 CLI > JSON > 环境 > 布局，JSON 相对路径基于其文件目录。历史/可选脚本内的本机路径保留原文并在代码索引登记，不作为默认分派。
- `config/RAP_inference.yaml` 为推理配置；受维护CPU训练入口scripts/training/train.py与config/RAP_train.yaml已通过Tiny工程验收，curate入口目前仅合成JSON。A4“入口缺失”为历史观察；真实数据、默认RAP完整训练/精确恢复仍未验收，项目Muon未安装，见[训练审计](environment/TRAINING.md)。
- 旧安装脚本和环境观察是来源证据，不是针对未选定服务器的已验证安装方案。A4 已形成[环境说明](environment/README.md)，区分当前 CPU 受查结果、参考版本与目标重建/训练保留项；不能把新说明称为经过干净重建的环境锁。

## 输出、状态和保全

- 新运行需新输出目录；不覆盖旧产物、不批量改写旧绝对路径、不删除失败/中断或零字节记录。旧 seal/freeze 与验证程序原样保留。
- 文档写成、工具可运行、输入通过、数值执行完成、独立验证通过、研究门槛通过、训练资格和科学贡献是不同状态，不能互相代替。
- 索引中的摘录保留来源和行号；某条 FAIL 可能是负对照，某条 PASS 可能只是功能检查。没有明确顶层状态时不自动归一为成功。
- 当前入口可更新，先备份原字节，再记录新哈希与接续证明。旧验证器对“现行入口等于旧哈希”的断言由新证明接续；历史科学哈希和原缺口不因此被修复。
- A1 的五个旧源码哈希、一份旧上下文版本、Linux 环境与动态引用保留项持续有效。具体见[缺口表](experiments/GAPS.md)。
