## Updating the handoff

- Update root AGENTS.md after every meaningful phase or interruption, not only at
  final completion. Keep it usable on its own and link details using repository paths.
- Record facts separately from plans: changed files, validation actually run,
  metrics and protocol, unresolved items, commit/worktree state and exact next step.
- Never mark a phase complete because a patch exists; record its acceptance checks.
- Preserve original results; repaired runs require new IDs and output directories.
- Keep dated history append-only. Resolve contradictory instructions in the current
  entry point instead of accumulating competing "next-session" blocks.
- Do not silently turn a historical empirical result into a general scientific claim.
- Before continuing, inspect both worktrees and relevant manifests. Do not overwrite
  someone else's edits or automatically rerun scripts that delete old products.
