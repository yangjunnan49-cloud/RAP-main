## 候选一：坐标扰动与旋转等变

这是一个具体的性质问题：输入坐标系变化后，预测是否按正确的变换律变化？C0
验证的是构造器/读取器的坐标算术，没有运行 RAP，不能替 RAP 回答这个问题。

本地 embedding.py 的 PointCloudEmbedding 对坐标逐分量计算多频 sin/cos，随后
通过普通 Linear 映射；point_cloud_dit.py 的最终速度由普通 MLP 输出。源码没有
强制任意 SO(3) 旋转下的等变约束。embedding.py 关于不加入 view index 的注释
指向视图排列性质，不能读成任意空间旋转的保证。普通坐标编码没有这种结构性
保证，并不证明某个已训练权重一定违反该性质；更不证明违反是当前误差的原因。

还必须分清分布与路径：各向同性 Gaussian 的分布旋转不变，不代表“重复同一个
整数随机种子、保持噪声数组不变”是逐路径的等变对照。合理的逐路径问题需要
连同噪声和向量量一起旋转，并处理锚点、中心化、尺度和特征路径。它也不能把
不同视图的独立坐标变换误当成公共世界规约；两者的目标变换律不同。

因此这里只记录静态结论：严格旋转等变未由该架构强制。没有实际权重/完整路径
测量，没有性质失败、故障原因或有效性证据。无监督的性质检查在原理上可定义，
但目前没有给出一个已观测且有用的任务缺陷、改善函数及强对照收益依据。追加
旋转次数、选最优旋转或做测试时增强也不能自动变成新的有效方法；本轮不执行。

## 候选二：把现存多个姿态交给全图离散选择

应区分跨边联合选择、同一对内的离散排序，以及从共同预测坐标派生的代数闭环。
最后一类对任意一组共享姿态都可恒等闭合，不能单独证明准确。真正的跨边选择
可以有不同的数学函数，但不能仅凭“图一致性”名字认定它新、有效或已可执行。

已读的 F2 原始报告、同日 postmortem、M1 和 Sep15 诊断给出限制：F2 N 的08
正例75对中，41对 K4 内没有正确候选，只有4对属于 R4 漏选正确候选；10个错误
接受内均无正确候选。选择器能改变选择或拒绝，却不能凭空增加候选支持。保持
相同接受规则只改 R4 的候选排序，其“原来被 R4 漏选的正确候选”机会数是4；
不能把这句话扩张成所有跨边优化/新接受规则的普遍上界。13个正确却被拒的结果
属于另一阶段；把它们作为可挽回收益需要另一个经过准入的观测/接受机制。

M1 的32个新增支撑导出候选在08只给41个原来缺候选的正例补出4个严格、2个内部
正确姿态，未达原门槛，不能现在拿来运行选择器。Sep15 的一致错误与标量排序
诊断使用较早银行，不能把它的2/9计数并入 F2 的1/10计数。Sep14 文献评审也已
把 max-mixture、保留多姿态和 null 假设列为已有方法；这里只引用既有评审的
边界，不声称完成了新的全网新颖性检索。

没有进行新拓扑、姿态、参考、模型或图优化计算。因此不宣称已排除所有图选择
方法；当前可用证据不足以证明它优于共同输入几何、普通图一致性或等总工作量
控制，也没有解除 F2/M1 原范围的停止。本轮不把它实现为另一个旧银行救援器。

## 后续决策

保留“接口完成”与“原始研究目标未完成”两项事实。新源码记录或一个真正不同、
可证伪且有现有观测依据的工程问题，才会改变下一步可执行范围。已有 KITTI
供给参考的工程研究不必等待所有历史真实性认证，但也不能把未知参考或新名字
当成收益。旧负结果只约束原构造，未完成试验仍未完成。

本轮停止新增科学负载：没有模型、训练、姿态指标、门槛改动、旧家族重试、作者
联系或 Git 同步。不会为了用满额度重复资源探测、无限做相同依赖审计，或启动
没有准入依据的实验。额度事实另记；小于100%仍可用，不得写成额度耗尽、研究
完成或用户要求暂停。
