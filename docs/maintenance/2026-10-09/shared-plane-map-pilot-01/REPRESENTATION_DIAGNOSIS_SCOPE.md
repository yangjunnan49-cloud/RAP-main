# Post-outcome representation diagnosis; no new pose arm

SMP1 outcomes are already exposed and all predictions validated. This separate
diagnostic is post-hoc, not a prospective confirmation, dense optimizer trial or
a density/threshold rescue of the closed SMP1 result. Run zero optimizers and
compute no new pose-reference errors. Do not change the SMP1 feature rules or gates.

For its exact same 32 source scans, compare the old even-row optimization points
with an exact superset: all first-return 0.5m voxel representatives after the
same range/vertical correction, before the old uniform 6000-point cap and half
split. Verify every old optimization point is present unchanged. Fixed old O
poses and the same 2m/4m feature construction are used only to census support.
Record voxel/point counts, eligible shared-feature counts, scan coverage and
plane normal direction spread. A denser superset can also add clutter and cause
feature rejection; changed coverage is not evidence of accuracy improvement.

Bind source code, helper, sealed SMP1 banks/results and the original source raw
scan hashes before computation. Diagnose whether the existing representation
preserves cross-scan surface support; do not infer physical identity, calibrated
confidence, the cause of every pose failure, or successful full SLAM.
This analysis counts toward the same new 1800s/2GiB/512MiB pilot ceiling.
