# KCS1 exact official camera-source page proposal

Both known local KITTI sequence trees lack standard camera directories across all22 sequences. A measured appearance branch therefore requires an actual image source, not assumed camera availability. The official odometry page is already cited by the project's M2 record; its exact main HTML is the proposed first object.

REQUEST_PLAN.json limits this to one main page/four necessary requests/256KiB body/120s complete transport,128MiB worker,2MiB dossier and unchanged fresh12GiB/2s host admission. It permits inspecting the page's published camera/odometry release pointers and access requirements only. No links, image files, ZIPs, archive HEAD/range requests, authentication form, scripts or API are followed. A failed attempt ends this source branch without retry or alternate channel.

This is a different source/task from the closed RegX share and canonical-JSON attempts. Those remain closed and are not retried. Exact authorization is requested under the existing AUTHENTICATION_DEPENDENCIES requirement; the broad strategy continuation does not identify this new page/envelope. A future image subset, if justified by a source/complete-population/camera-overlap contract, would need a separate concrete acquisition decision.
