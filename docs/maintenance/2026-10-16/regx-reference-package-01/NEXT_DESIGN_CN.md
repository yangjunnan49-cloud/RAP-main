# 调整后的顺序与入场条件

本轮已完成固定包的来源身份与结构验证。现在的科学动作停在参考解释前提，
不是继续增加点数、步数、阈值或同类模型实验。一个Paris_02场景不能代表
全数据集或独立泛化；完整JSONL及来源文档已被审阅，暴露状态必须保留。

1. 固定输入/参考契约。需要同一发布修订的实际加载、增强和评价代码证据，
   明确PLY是否原始或已增强、矩阵作用方向、逐样本增强与全局规范、平移
   归一化场景尺度、图边口径。先准备精确源码身份和最小来源清单，不用
   当前剩余下载裕量获取计划外文件，也不联系作者。当前8文件例外仅覆盖
   这8文件；新增公开源码获取应作为独立明确范围。
2. 在后续独立协议中，用固定合成点与解析SE(3)验证加载/反向变换/规范不变性，
   与参考数值数值合法性分开。当前协议禁止坐标和姿态运算，故本轮不执行。
   共享文件矩阵token不同不能直接判错，需区分全局规范与相对关系。
3. 冻结输入墙。预测器只允许经审定的点负载和文件顺序；参考矩阵、图重叠、
   JSONL元数据归评价端。每一输入变换和采样必须有来源、身份、随机性约定，
   全部预测先封印再评价；不得用参考改善输入或挑选视图。
4. 只有此前提通过，才写一个有可证伪机制的比较设计。普通全几何/直接控制、
   同输入、有效容量与总工作量必须齐全。该小包最多承载接口可用性，不能
   作为新方法优势证据；新效能队列及资源/获取范围须另行确定。

当前未实施模型、拟合、求解、参考重算或任何旧家族复活。原demo参考构造仍
待原作者/原始来源认证；保留未发送询问信，尊重用户暂不发送的决定。没有
依赖解除前，不用无关原型填满账号额度，也不把停止称为原目标完成。
