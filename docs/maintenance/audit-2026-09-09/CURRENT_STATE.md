## 2. 真正运行的系统

默认离线：真实数据加载 → KISS-ICP → 关键帧 → 邻近候选 + ring-key shortlist SC → RAP pairwise → overlap≥0.7 且 mean_dist≤2.5 m → relfloor + Huber PGO → 轨迹/地图。

默认流式：ROS 播放器 → KISS-ICP → 时间戳配对与关键帧 → 全库 SC + 簇持久性 + 优先队列 → 相同 pairwise 门控 → relfloor + Huber + NMS(w=10) → 地图/轨迹。

**两者不是同一套检索策略。** 离线默认候选预算 12，NMS 关闭；流式总预算默认不封顶但每关键帧有预算，NMS 开启。离线还强制最后一帧为关键帧。论文表格必须标出这些差异。
