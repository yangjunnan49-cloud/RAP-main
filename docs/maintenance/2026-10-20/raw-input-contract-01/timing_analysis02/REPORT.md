# 固定耗时轨迹的理想FIFO分析

这是一项调度算术，不是并行性能实测。全部36单元/73776帧调用纳入；两模式使用同一分区和两个预定到达场景。

A为读盘/哈希+预处理/输入审计+独立E0前端，B为原生地图/闭环；K的E0时钟仅包含近零计时开销。串行输入是每帧实测总耗时，额外等待计入合成到达延迟；它不同于原报告的单帧循环耗时。固定合成到达为每100ms一帧，并非实测传感器时钟。理想队列只统计准备完毕而地图尚未开始的包，不等于实际内存或包含正在处理的帧。

所有分区、FIFO单调/完整顺序、串行累计与事件队列均校验通过，3个手算fixture先于真实耗时分析。测量发生于串行共享机器，重叠下的核竞争、IPC、缓存、数组拷贝、进口/日志/最终细图和输出未知或未建模。不能据此宣称在线10Hz或实测加速；完整原始系统指标和各失败保护不变。

若理想模型仍有超期，它不能支撑严格每帧100ms期限；可以另行定义有限的运行时等价工程验证，但须先冻结接口/顺序/等价门槛、资源及强串行对照。此分析不自动启动原始扫描重放/新求解器/参数调整。
