## 实验与维护索引

索引建立于 A1 的不可变清点和本轮新增维护档案，首版 **482 个档案条目**，覆盖研究/维护范围、日期记录、外部档案、旧输出、保全副本、报告、组会和工具集合。条目不等于独立实验数；嵌套记录、同文副本与容器明确区分。

- docs/experiments/CATALOG.md：按类别和日期的可读入口。
- catalog.jsonl / catalog.csv：稳定 ID、目的、原始来源、协议、代码/输入版本证据、执行/登记状态、产物规模、失败/停止/预算摘录、seal 位置及约束。
- README.md：字段、未知值、状态含义、查询方法和关键结论。
- GAPS.md：五个旧源码哈希、一个旧 AGENTS 中间版本和后续阶段依赖。
- PATHS.md / evidence_manifest.json：根 ID、旧路径、相同字节副本及报告镜像的解释。
- MEETINGS.md：材料定位，成品版本、制作源码与缓存处理仍待 A6。

25 个关键档案的明确状态以原报告/交接和人工整理的 CURATED_STUDIES.json 为依据；其它 execution_state 保留 null，并提供原 STATUS 声明及带来源/行号的原文摘录。FAIL、PASS、COMPLETE 可能指负对照或单次尝试，生成器不把这些词自动变成整个研究的成功结论。

协议/来源/版本/seal 字段表示证据位置，不表示其中全部哈希已无差异。A1 的科学来源、物理参考、预算和复现缺口继续有效；未对历史数据重新算指标、排序或扩大接受数。
