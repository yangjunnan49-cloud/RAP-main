## 逐文件处置表

- ASSET_LEDGER.jsonl / DISPOSITION_DRY_RUN.csv：每个文件或链接的归属、依据、Git 状态、校验值、保护状态、建议目标、处置动作、现存位置与可用保全副本。
- DIRECTORY_LEDGER.jsonl：目录条目；空目录也有记录。
- ROOT_MAPPING.json：保持仓库边界的迁移暂存根映射草案，不是已应用的最终目录结构。
- CLASSIFICATION_SUMMARY.json / CACHE_CANDIDATES.jsonl：类别与动作统计，以及源码配对后的缓存候选。

所有动作均为 dry-run，action_executed=false。类别为保守归属，不等于已逐个审阅全部实验或组会内容。两个安装/下载残留（cuda-keyring deb、wget-log）仍保留待 A4 核对。当前实验和历史数据均保留，不以文件名、旧日期、失败状态或 Git ignored/untracked 判断删除。
